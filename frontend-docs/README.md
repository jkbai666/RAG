# 文档管理端

独立的 Vue 文档管理界面，对应 UC-001 v2 的 T-03。只访问 Java 后端，不直接访问 MySQL、Chroma 或模型服务，不接入集团后台框架，也不提供账号功能。

## 安装与启动

使用 Node.js 24、npm。首次安装或按锁文件重装：

```powershell
cd D:\BYS\RAG\frontend-docs
npm ci
npm run dev
```

访问 `http://127.0.0.1:5174`。开发服务器固定绑定回环地址、端口 5174，`strictPort` 开启；端口被占用时直接失败，不自动切换端口。

如需修改后端或问答端地址，复制 `.env.example` 为 `.env.local`，修改后重启开发服务器：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `VITE_API_TARGET` | `http://127.0.0.1:8088` | Vite 开发服务器的 `/api` 代理目标，不改写路径 |
| `VITE_CHAT_URL` | `http://127.0.0.1:5173` | 在新标签页打开独立问答端，设置 `noopener noreferrer` |

`VITE_*` 配置不是保密存储。不要在前端环境文件中填写模型 API Key、数据库口令或其他凭据。此应用不适合直接暴露到公网。

## 构建与研发检查

```powershell
npm test
npm run build
npm run preview
```

- `npm test` 使用 Node 内置测试运行器，覆盖文件校验、显示规则、HTTP 契约调用、轮询、切换时过期响应隔离、上传与删除重试。测试中的契约响应是局部研发验证，不代表真实后端或浏览器验收通过。
- `npm run build` 先运行 `vue-tsc --noEmit`，再由 Vite 输出到 `dist/`。
- `npm run preview` 在 `127.0.0.1:5174` 预览构建产物，不提供开发服务器的 `/api` 代理。访问真实数据应使用开发服务器，或由部署服务器将 `/api` 反向代理到 Java 后端；不要将预览服务器当成完整部署。
- Vue 固定 `3.5.44`，Vite 固定 `8.3.4`。具体依赖版本见 `package.json` 和 npm 生成的 `package-lock.json`。

## 页面行为

- 每次选择一个 `.txt`、`.md` 或 `.pdf`，不超过 20 MiB。客户端拦截空文件、超限和不支持的扩展名；文件内容、编码及有效文本仍以服务端校验为准。TXT、Markdown 使用 UTF-8；PDF 只支持文本层，不做 OCR。
- 列表按导入时间倒序显示完整文件名、格式、大小、导入时间、处理状态和块数。存在处理中文档时，每次列表请求完成后等待 1.5 秒再次读取；列表错误时暂停轮询并显示重试入口。页面卸载时取消请求和计时器。
- 仅就绪文档可查看分块。正文从分块接口读取，以纯文本保留换行显示，不自行重切分、不截断，也不使用 `v-html`。显示原文索引、Unicode 码点字符数和后端提供的页码；未知页码明确显示“页码未提供”。每页 20 块。
- 删除前通过原生对话框确认，说明会同时移除分块和检索数据；取消按钮默认获得焦点。处理中不可删除，删除请求未完成时不允许重复操作。只有收到服务端 204 后才移除本地记录；失败时保留记录、显示原因，并支持再次确认删除。
- 上传、列表、分块和删除的技术错误分别显示，不冒充成功或空数据。上传超时或连接中断时，服务端可能已经收到文件，应先刷新列表再决定是否重新上传，避免创建重复文档。
- 两个前端没有共享内存同步。跳转到问答端不代表其知识库状态已即时更新。

## 文件组织

- `src/lib/`：共享契约类型、API 请求和显示/校验函数。
- `src/composables/useDocuments.ts`：列表轮询、选择与分块分页、上传与删除状态。
- `src/components/`：上传、文档列表、分块全文与删除确认。
- `src/style.css`：暖白与墨绿样式、双栏/窄屏布局、焦点和减少动态效果。
- `tests/`：不依赖真实后端或浏览器的研发测试。

## 安全与集成边界

共享接口以 `D:\BYS\RAG\docs\api-contract.md` 为准。本工程不修改契约，不内置模拟服务或伪造的业务数据。文档内容始终是不可信文本。

文档会交给后端提取和索引；若后端使用外部模型服务，分块向量生成会向该服务发送文档文本，问答也可能发送问题及选中的分块。敏感资料导入前应确认后端模型配置及数据使用许可，前端不管理模型凭据。

真实后端联调与 Playwright 页面验收由主 agent 集成。需要实际核验：TXT/MD/PDF 导入及失败、实际索引全文、PDF 页码、跨存储删除失败与恢复、1440×900 和 390×844、键盘 Tab/Enter/Escape、对话框焦点返回、长文件名与长正文、无页面级横向溢出。构建和局部测试不能替代这些检查。
