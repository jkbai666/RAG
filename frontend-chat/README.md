# 知识库问答端

独立的 Vue 3 问答工程，调用共享 Java 后端。仅实现文档问答、等待与错误反馈、知识库状态和来源原文，不接入集团后台框架。

## 环境与命令

需要 Node.js 24 和 npm。依赖版本已固定，`package-lock.json` 用于复现安装。

```powershell
cd D:\BYS\RAG\frontend-chat
npm ci
Copy-Item .env.example .env.local
npm run dev
```

开发地址固定为 `http://127.0.0.1:5173`。端口被占用时直接报错，不自动换端口。

```powershell
# 局部逻辑与 HTTP 契约测试（Node.js 内置测试工具）
npm test
# TypeScript / Vue 类型检查，再生成 dist 静态文件
npm run build
# 本地查看构建产物；需要先停止同端口的开发服务器
npm run preview
```

`preview` 只用于查看静态产物，不配置开发代理。正式部署应由 Web 服务将同源 `/api` 转发到 Java 后端。需要联调后端时使用 `npm run dev`。

## 本地配置

复制 `.env.example` 为 `.env.local`，修改后重启 Vite。不要在前端填写模型密钥，模型配置仅保存在后端。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `VITE_API_TARGET` | `http://127.0.0.1:8088` | Vite 开发服务器的 `/api` 代理目标。 |
| `VITE_DOCUMENTS_URL` | `http://127.0.0.1:5174` | 文档管理入口，新标签页打开，带 `noopener noreferrer`。仅接受 HTTP(S) 链接，无效值回退到本机默认地址。 |

构建时 `VITE_DOCUMENTS_URL` 会写入前端产物；`VITE_API_TARGET` 不会替代正式部署的反向代理配置。所有 `VITE_` 变量都不应包含凭据。

## 行为与边界

- 首次进入及窗口重新获得焦点时调用 `GET /api/knowledge/status`。状态加载失败可重试；状态未知、刷新中、空库、模型缺少配置时禁用发送。`modelConfigured` 仅表示配置齐全，不保证模型服务可达。
- 每次仅提交 `POST /api/chat` 的 `{ question }`，不提交之前的消息。不支持多轮上下文或流式输出。
- 问题按 Unicode 码点计数，最多 2000 字符，空白输入不可发送。中文输入法选词期间的 Enter 不发送；普通 Enter 发送，Shift + Enter 换行。
- 等待期间阻止重复请求，输入区只读。成功后清空输入；失败保留原输入，并允许修改后重新发送。同一失败问题重试复用该失败消息。
- `grounded=false` 显示“未找到足够依据”，不当作技术错误。服务错误显示中文原因，不使用模拟答案兜底。
- 来源使用本条回答返回的文件名、分块编号、PDF 页码和完整原文。两级折叠分别查看来源列表及分块原文，不自行补造来源。所有内容按纯文本展示，不使用 `v-html`。
- 消息与来源快照仅保存在当前页内存中。新标签页打开文档管理不会清空消息；重新获取知识库状态也不会删改已有回答。刷新或关闭页面后清空，不使用浏览器存储。
- 状态请求超时为 15 秒，问答请求超时为 180 秒；超时显示可重试错误。页面卸载会取消尚未完成的请求。

## 验证范围

`npm test` 覆盖 Unicode 字数、发送门禁、重复提交、失败重试、独立问题、无依据回答、来源快照、状态竞态、请求取消和 HTTP 契约/错误处理。测试响应只用于局部检查，不代表真实模型或后端验收。

`npm run build` 同时执行类型检查及生产构建。真实后端、模型、跨前端联调与浏览器验收由主 agent 完成；重点检查 1440×900 和 390×844、长中文与长文件名、键盘和中文输入法、焦点可见性、屏幕阅读器等待/错误提示，以及从文档管理切回后的状态更新。
