## 持续优化管理

每次有行为变化的优化沿用 `02-需求实现/UC-NNN-中文短名称/`，不覆盖历史版本记录。缺陷修复继续放在独立的 `03-缺陷修复/BUG-NNN-中文短名称/`。

- 规格记录目标、范围、方案取舍、验收标准和批准状态。
- 范围确认后形成实施计划，并持续记录改动位置、原因、测试命令、实际结果、未验证项和遗留风险；需要详细证据时另附验证记录。
- 实现并验证后，再同步当前架构与接口契约；文档必须区分“拟议、已实现、已验证”。
